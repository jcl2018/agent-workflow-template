# wiki-catchup: design

## Problem
Main's Documentation page reads STALE (2 commits since the page), so `docs.py publish` refuses and the GitHub wiki is behind
(#3875). automation-table-health added a line to the page's Tests intro (bac3df1d); the release's own wiki commit (fb7e1cfe)
removed it again, because the Tests section is generated and must equal a fresh render (DOC-9). Edit and removal cancel, so
the page reads as before. Once the branch is merged, git's history simplification hides both commits, so the code commits
look newer than the page.

## Approaches
1. Re-add the sentence somewhere the page allows. No such place exists: Tests is generated, text between the Review line
   and Problem is refused (SECTIONS), and Problem, Requirements, Non-goals and Success metrics are the owner's reviewed text.
   Cost: none that works. Risk: LOCKED, or the next audit deleting it again.
2. Read the page's judged commits with `--full-history` in `docs.py problems()`, so a page a branch touched is judged by that
   branch's commits whether or not the page ended up different. Cost: one flag. Risk: a page edited and put back counts as
   judged; the commit exists, a human or the audit looked at it.

## Chosen
2. It removes the cause for every page, and Documentation on main turns current with no page edit and no owner decision.
A toy builds a repo, edits a page and puts it back on a branch, merges it, and expects no STALE (seen red on the old line),
then expects STALE again after a later code change.

## Done lines
- `docs.py publish --dry-run` on the merged head reports no STALE page: met by the fix; the release publishes it after merge.
- "a toy shows the release wiki step keeping a hand-added Tests-intro line": as worded it cannot be met, since the Tests
  section is generated by design and the mechanical fix is meant to remove hand text there. The toy shows what the line was
  for: a page the wiki step edited and reverted stays judged after the merge.

## Open questions
None for the owner; the done-line wording is raised with the operation session.
